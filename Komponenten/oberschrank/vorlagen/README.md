# Vorlagen Oberschrank

Jürgens ursprüngliche Dynamic Components, aus denen die Oberschrank-Komponente entstanden ist (siehe [TCN-Plan, Abschnitt Oberschränke](../../../docs/plaene/tcn-export.md)). Nur zum Nachschlagen; verwendet wird die Erweiterung `oberschrank.rbz`.

* `Oberschrank.skp`: 400 × 700 × 400 mm, eine Tür
* `Oberschrank_Doppeltuer.skp`: 600 × 700 × 400 mm, zwei Türen
